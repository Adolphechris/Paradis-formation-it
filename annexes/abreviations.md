# Annexes — Dictionnaire des Acronymes & Abréviations IT & Banque

> [!NOTE]
> Ce dictionnaire répertorie l'ensemble des acronymes et termes techniques indispensables pour tout ingénieur et technicien informatique travaillant pour la **Banque Centrale du Congo (BCC)**.

---

## 🏛️ 1. Normes & Concepts Bancaires & Monétaires

| Acronyme | Définition Complète | Signification & Contexte Métier BCC |
| :--- | :--- | :--- |
| **BCC** | Banque Centrale du Congo | Institution nationale d'émission et de régulation financière de la RDC. |
| **SWIFT** | Society for Worldwide Interbank Financial Telecommunication | Réseau international sécurisé de messagerie interbancaire. |
| **RTGS** | Real-Time Gross Settlement | Système de règlement brut en temps réel pour gros montants interbancaires. |
| **ACH** | Automated Clearing House | Chambre de compensation automatisée pour paiements de masse. |
| **KYC** | Know Your Customer | Obligation légale de vérification de l'identité des clients. |
| **AML** | Anti-Money Laundering | Lutte contre le blanchiment de capitaux et le financement du terrorisme. |
| **IBAN** | International Bank Account Number | Identifiant international de compte bancaire. |
| **BIC** | Bank Identifier Code | Code d'identification unique d'une banque (également appelé SWIFT code). |

---

## 🔒 2. Cybersécurité & Gouvernance IT

| Acronyme | Définition Complète | Signification & Contexte Métier BCC |
| :--- | :--- | :--- |
| **ISO 27001** | Norme de Système de Management de la Sécurité de l'Information | Standard international définissant les exigences de sécurité du SI. |
| **ITIL** | Information Technology Infrastructure Library | Référentiel des bonnes pratiques de gestion des services IT (ITSM). |
| **PCA** | Plan de Continuité d'Activité | Ensemble de mesures garantissant le fonctionnement en cas de crise majeure. |
| **PRA** | Plan de Reprise d'Activité | Procédures de secours pour reconstruire le SI après un sinistre. |
| **SIEM** | Security Information and Event Management | Gestion et analyse centralisée des événements et alerte de sécurité. |
| **SOC** | Security Operations Center | Centre de surveillance opérationnelle de la cybersécurité 24/7. |
| **DPO** | Data Protection Officer | Délégué à la protection des données personnelles (RGPD/Lois RDC). |
| **MFA** | Multi-Factor Authentication | Authentification exigeant au moins 2 facteurs distincts. |

## 🐧 3. Systèmes & Infrastructure Linux / Windows

| Acronyme | Définition Complète | Signification & Contexte Métier BCC |
| :--- | :--- | :--- |
| **AD DS** | Active Directory Domain Services | Service d'annuaire et d'authentification centralisé Microsoft. |
| **GPO** | Group Policy Object | Objet de stratégie de groupe contrôlant les postes et serveurs AD. |
| **SSH** | Secure Shell | Protocole d'administration à distance chiffré. |
| **UFW** | Uncomplicated Firewall | Interface de gestion simplifiée du pare-feu Linux iptables/nftables. |
| **CLI** | Command Line Interface | Interface en ligne de commande texte. |
| **GUI** | Graphical User Interface | Interface graphique utilisateur. |
| **PID** | Process IDENTIFIER | Identifiant numérique unique d'un processus système. |
| **SGBD** | Système de Gestion de Base de Données | Logiciel de stockage et de manipulation de données (ex: PostgreSQL). |

## 🌐 4. Réseaux & Cloud TCP/IP

| Acronyme | Définition Complète | Signification & Contexte Métier BCC |
| :--- | :--- | :--- |
| **TCP/IP** | Transmission Control Protocol / Internet Protocol | Suite de protocoles fondamentaux d'Internet et des réseaux d'entreprise. |
| **DHCP** | Dynamic Host Configuration Protocol | Attribution automatique d'adresses IP et paramètres réseau. |
| **DNS** | Domain Name System | Système de résolution des noms de domaine en adresses IP. |
| **CIDR** | Classless Inter-Domain Routing | Notation de masque de sous-réseau (ex: /24). |
| **VLAN** | Virtual Local Area Network | Segmentation logique d'un réseau physique. |
| **VPN** | Virtual Private Network | Tunnel chiffré reliant deux réseaux ou postes distants. |
| **IaaS / PaaS / SaaS** | Infrastructure / Platform / Software as a Service | Modèles de services d'informatique en nuage (Cloud). |
