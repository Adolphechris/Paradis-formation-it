# PARADIS — Programme d'autoformation intensive en informatique

## ⚠️ Avertissement

PARADIS est un programme structuré de formation personnelle.
C'est un parcours d'autoformation organisé selon les standards
méthodologiques de l'enseignement ouvert et à distance (ODL, inspiré d'UNISA),
conçu pour acquérir en un temps record les compétences pratiques et stratégiques d'un
Bachelor of Information Technology (BIT) et devenir opérationnel pour
l'emploi (support technique, administration systèmes/réseau, analyse de
données, développement web).

## Structure du dépôt

- `01-feuille-de-route/` — vision, méthodologie, système d'évaluation
- `02-tome-p0-socle/` — environnement de travail, bureautique, web front-end, Git, Linux
- `03-tome-p2-fondations/` — Python, structures de données, SQL, réseaux, Bash
- `04-tome-p3-specialisations/` — administration systèmes, analyse de données, développement web
- `05-tome-p4-cloud-securite/` — cloud, sécurité, gouvernance IT, anglais technique
- `06-tome-p5-preparation-tests/` — banques de questions, simulations d'entretien
- `07-portfolio/` — projets réalisés au fil du programme
- `annexes/` — glossaire des abréviations et interactions
