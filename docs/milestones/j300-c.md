# J300c — Soutenance du Projet Bachelor BIT

> [!IMPORTANT]
> **MILESTONE J300 — DIPLÔME BACHELOR BIT**  
> Cette soutenance valide votre capacité à présenter et défendre votre projet d'infrastructure IT devant un jury.  
> **Condition de Réussite :** Présentation ≥ 70/100 points.

---

## 🎯 Objectifs de la Soutenance

- 🎤 Présenter votre projet d'infrastructure IT de manière structurée.
- 💼 Démontrer votre compréhension des choix techniques.
- 🧠 Répondre aux questions du jury sur les aspects techniques, sécurité et stratégiques.
- 📊 Valider votre passage du Bachelor BIT vers le Master Cybersecurity.

---

## 🎤 Guide de Présentation

### 1. Introduction (2 min)
> "Bonjour, je m'appelle Adolphe. Je viens de valider le Semestre 1 à 4 du parcours PARADIS IT Masterclass. Aujourd'hui, je vous présente l'infrastructure IT que j'ai conçue pour une entreprise de 100 employés sur le marché nord-américain."

### 2. Architecture réseau (3 min)
- Présentez le schéma réseau.
- Expliquez les VLANs : pourquoi 4 VLANs ? Quels rôles ?
- Montrez les règles firewall (ports ouverts/fermés).
- Expliquez le plan d'adressage IP.

### 3. Serveurs Linux (3 min)
- Présentez web-01 (Nginx) et db-01 (PostgreSQL).
- Montrez les scripts de déploiement.
- Expliquez les choix de sécurité (SSH, permissions, UFW).

### 4. Serveur Windows (2 min)
- Présentez ad-01 (Active Directory).
- Expliquez la structure des utilisateurs et des GPO.
- Montrez le script de création des utilisateurs.

### 5. Sécurité (3 min)
- Résumez les mesures de sécurité.
- Expliquez le principe du moindre privilège.
- Montrez le rapport de sécurité.

### 6. Monitoring & Sauvegardes (2 min)
- Présentez Prometheus + Grafana.
- Expliquez le plan de sauvegarde (fréquence, rétention, destination).

### 7. Défis & Leçons apprises (2 min)
> "Le plus grand défi a été de faire cohabiter Linux et Windows dans un même réseau. J'ai résolu ça en utilisant un VLAN dédié aux serveurs et en sécurisant les communications avec des règles firewall strictes."

### 8. Questions du jury (3 min)
- Préparez-vous à répondre sur : sécurité, choix techniques, alternatives, améliorations futures.

## ❓ Banque de Questions du Jury

### Questions techniques

**Q1 : Pourquoi avoir choisi 4 VLANs ?**
- A) Pour isoler les flux et limiter la propagation d'une attaque
- B) Pour rendre le réseau plus compliqué
- C) Parce que c'est à la mode
- D) Aucune raison

*Réponse attendue : A — Segmentation réseau = sécurité + performance.*

**Q2 : Pourquoi avoir désactivé le login root SSH ?**
- A) Parce que root est la cible privilégiée des attaquants
- B) Pour embêter les utilisateurs
- C) Parce que SSH est lent
- D) Aucune raison

*Réponse attendue : A — Root est le compte le plus puissant ; le désactiver réduit la surface d'attaque.*

**Q3 : Quelle est la différence entre UFW et nftables ?**
- A) UFW est une interface simplifiée, nftables est le moteur sous-jacent
- B) UFW est plus puissant que nftables
- C) Ce sont deux outils identiques
- D) UFW ne fonctionne pas sur Linux

*Réponse attendue : A — UFW (Uncomplicated Firewall) est une surcouche de nftables/iptables.*

**Q4 : Pourquoi séparer les serveurs web et base de données ?**
- A) Pour isoler les risques : si le web est compromis, la DB reste protégée
- B) Parce que c'est plus joli
- C) Pour utiliser plus de machines
- D) Aucune raison

*Réponse attendue : A — Séparation des rôles = défense en profondeur.*

**Q5 : Qu'est-ce que le principe du moindre privilège ?**
- A) Un utilisateur n'a que les droits strictement nécessaires
- B) Tous les utilisateurs sont administrateur
- C) Les droits sont attribués aléatoirement
- D) Il n'y a pas de gestion des droits

*Réponse attendue : A — Moindre privilège = réduction de la surface d'attaque.*

---

### Questions stratégiques

**Q6 : Si un attaquant compromet le serveur web, comment il peut pivoter vers la base de données ?**
- A) Via des failles SQL injection, credentials en dur, ou mouvement latéral
- B) Il ne peut pas
- C) Il doit redémarrer le serveur
- D) Il doit appeler le support technique

*Réponse attendue : A — Plusieurs vecteurs : SQLi, credentials volés, pivot réseau.*

**Q7 : Comment vous adaptez-vous aux exigences de conformité (PCI DSS, RGPD) ?**
- A) Chiffrement des données sensibles, logs d'audit, sauvegardes, documentation
- B) En ignorant ces réglementations
- C) En installant un antivirus
- D) En changeant les mots de passe tous les jours

*Réponse attendue : A — Conformité = technique (chiffrement) + processus (logs, sauvegardes, docs).*

**Q8 : Quel est votre plan en cas de ransomware ?**
- A) Sauvegardes immuables (3-2-1), isolation réseau, PRA, communication
- B) Payer la rançon immédiatement
- C) Éteindre tous les serveurs
- D) Ignorer et attendre

*Réponse attendue : A — 3-2-1 (3 copies, 2 supports, 1 hors site) + isolation + PRA.*

**Q9 : Comment gérez-vous les mises à jour de sécurité ?**
- A) Patch management automatisé avec tests préalables
- B) Pas de mise à jour pour éviter les casses
- C) Mise à jour manuelle une fois par an
- D) Ignorer les alertes de sécurité

*Réponse attendue : A — Patch régulier, testé, automatisé dans la mesure du possible.*

**Q10 : Quelle est la prochaine étape pour cette infrastructure ?**
- A) Ajouter un VPN, un SIEM, un PRA, de la formation aux employés
- B) Tout supprimer et recommencer
- C) Ne rien faire
- D) Ajouter plus de serveurs sans plan

*Réponse attendue : A — Vision d'amélioration continue (VPN, SIEM, PRA, formation).*
