## ❓ Banque des 60 Questions de l'Examen Massif Master J600a

**Q1 : En architecture Zero-Trust (NIST 800-207), quel principe fondamental remplace la sécurité périmétrique traditionnelle ?**
- A) Never Trust, Always Verify — aucune confiance implicite basée sur la localisation réseau
- B) Faire confiance au réseau local LAN
- C) Utiliser un seul mot de passe fort
- D) Autoriser tous les utilisateurs du bureau

*Réponse : A — Le Zero-Trust impose de vérifier et d'authentifier chaque requête indépendamment de la provenance réseau.*

**Q2 : Quel standard ISO révisé en 2022 définit les exigences d'un Système de Management de la Sécurité de l'Information (SMSI) ?**
- A) ISO 9001
- B) ISO 27001:2022
- C) ISO 14001
- D) ISO 31000

*Réponse : B — L'ISO 27001:2022 est la norme de référence internationale pour le SMSI.*

**Q3 : Dans une attaque Active Directory, que permet d'obtenir la technique 'Kerberoasting' ?**
- A) Des tickets TGS contenant le hash NTLM/RC4 de comptes de service ayant un SPN configuré
- B) Le mot de passe de l'administrateur du domaine en clair
- C) La suppression de l'annuaire
- D) Un accès Wi-Fi

*Réponse : A — Kerberoasting extrait les tickets TGS pour les casser hors-ligne et retrouver les mots de passe des comptes de service.*

**Q4 : Dans le cadre de la directive européenne NIS 2, quelle est l'obligation de notification en cas d'incident cyber majeur ?**
- A) Alerte précoce sous 24h et rapport d'incident sous 72h auprès de l'autorité nationale (ex: ANSSI)
- B) Notification sous 1 mois
- C) Aucune notification obligatoire
- D) Envoyer un e-mail au maire

*Réponse : A — NIS 2 exige une alerte initiale sous 24h et une notification complète sous 72h.*

**Q5 : Quel algorithme de chiffrement asymétrique Post-Quantique a été standardisé par le NIST (FIPS 203) pour l'échange de clés ?**
- A) ML-KEM (Kyber)
- B) RSA-4096
- C) AES-256-GCM
- D) ECC secp256k1

*Réponse : A — ML-KEM (basé sur Crystals-Kyber) est le standard FIPS 203 pour le chiffrement post-quantique.*

**Q6 : Dans un SOC, quel est l'objectif principal d'un outil SOAR (Security Orchestration, Automation and Response) ?**
- A) Automatiser l'exécution des playbooks de réponse aux incidents pour réduire le MTTR
- B) Remplacer l'antivirus des postes
- C) Imprimer des rapports papier
- D) Sauvegarder les bases de données

*Réponse : A — Le SOAR orchestre et automatise les actions de réponse pour accélérer la gestion des alertes.*

**Q7 : Lors d'une analyse forensique mémoire sous Volatility 3, quelle commande permet d'identifier les injections de code et shellcodes suspects dans les processus ?**
- A) windows.malfind
- B) windows.pslist
- C) windows.netscan
- D) windows.info

*Réponse : A — Le plugin malfind détecte les pages mémoire exécutables et écrites dynamiquement (VAD) typiques des injections.*

**Q8 : Dans Kubernetes, quel composant de contrôle doit impérativement être durci et chiffré au repos pour protéger les secrets du cluster ?**
- A) etcd
- B) kube-proxy
- C) CoreDNS
- D) Ingress Controller

*Réponse : A — etcd contient l'état complet du cluster et tous les secrets Kubernetes ; son chiffrement est critique.*

**Q9 : Quelle vulnérabilité Web OWASP Top 10 permet à un attaquant de forcer un serveur d'application à émettre des requêtes HTTP non sollicitées vers le réseau interne ?**
- A) SSRF (Server-Side Request Forgery)
- B) XSS (Cross-Site Scripting)
- C) CSRF (Cross-Site Request Forgery)
- D) SQLi

*Réponse : A — Le SSRF détourne le serveur pour interroger des ressources internes non accessibles depuis l'extérieur.*

**Q10 : Dans le modèle de maturité EBIOS RM (ANSSI), quel est le but de l'Atelier 3 ?**
- A) Identifier les scénarios stratégiques d'attaque et les couples (Source de risque / Objectif visé)
- B) Rédiger le contrat d'assurance
- C) Acheter des pare-feux
- D) Formater les disques durs

*Réponse : A — L'Atelier 3 d'EBIOS RM évalue les scénarios stratégiques de menace.*

**Q11 : Quel protocole sécurisé permet d'attester l'identité cryptographique des workloads dans un cluster Kubernetes Zero-Trust ?**
- A) SPIFFE / SPIRE
- B) Telnet
- C) FTP
- D) HTTP 1.1

*Réponse : A — SPIFFE/SPIRE fournit des identités SVID (X.509) cryptographiques éphémères aux workloads.*

**Q12 : En cryptographie moderne, quelle propriété garantit qu'un compromis des clés privées long terme n'affecte pas la confidentialité des sessions passées ?**
- A) Perfect Forward Secrecy (PFS)
- B) Chiffrement symétrique ECB
- C) Hachage MD5
- D) Hachage SHA-1

*Réponse : A — Le PFS régénère des clés de session éphémères (Diffie-Hellman) pour chaque connexion.*

**Q13 : Quel outil décompilateur libre développé par la NSA est la référence pour l'analyse statique et le Reverse Engineering de binationaux ?**
- A) Ghidra
- B) Wireshark
- C) Nmap
- D) Putty

*Réponse : A — Ghidra est la suite logicielle de référence pour le Reverse Engineering et la décompilation C/C++.*

**Q14 : Dans Active Directory, que permet la technique 'DCSync' exploitée par la Red Team ?**
- A) Simuler le comportement d'un Contrôleur de Domaine pour répliquer et obtenir les hashs de mots de passe de tous les utilisateurs (dont krbtgt)
- B) Redémarrer le serveur
- C) Imprimer un fichier
- D) Formater la base

*Réponse : A — DCSync utilise le protocole DRSUAPI pour demander la réplication des secrets AD sans exécuter de code sur le DC.*

**Q15 : Quel contrôle de sécurité CIS Benchmark permet de bloquer la mémoire non exécutable au niveau processeur pour contrer les Buffer Overflows ?**
- A) DEP (Data Execution Prevention) / NX Bit
- B) DHCP Snooping
- C) DNSSEC
- D) RAID 5

*Réponse : A — DEP/NX marque les plages mémoire de données comme non-exécutables pour empêcher le lancement de shellcodes.*

**Q16 : Dans un pipeline CI/CD DevSecOps, quel outil SAST permet de scanner les fichiers Infrastructure-as-Code Terraform à la recherche de failles de sécurité ?**
- A) Checkov / TFSec
- B) Git push
- C) Docker run
- D) Npm start

- A) Règles SIGMA

**Q20 : Dans le cadre du RGPD, quel est le délai légal maximal pour notifier une violation de données personnelles à la CNIL ?**
- A) 72 heures au plus tard après en avoir pris connaissance
