### 2. Scripts de déploiement Linux

**Script 1 : Déploiement serveur web**
```bash
#!/bin/bash
# deploy_web.sh
# Déploie Nginx avec configuration sécurisée sur web-01

# 1. Mise à jour système
apt update && apt upgrade -y

# 2. Installation Nginx
apt install nginx -y

# 3. Durcissement SSH
sed -i 's/#PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
sed -i 's/#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
systemctl restart sshd

# 4. Configuration firewall
ufw allow 22/tcp
ufw allow 80/tcp
ufw allow 443/tcp
ufw enable

# 5. Page d'accueil personnalisée
cat > /var/www/html/index.html << 'EOF'
<h1>Bienvenue sur l'infrastructure BCC</h1>
<p>Serveur web sécurisé — Deployé par Adolphe</p>
EOF

echo "Déploiement web-01 terminé."
```

**Script 2 : Sauvegarde automatisée**
```bash
#!/bin/bash
# backup_daily.sh
# Sauvegarde quotidienne de la base de données

DATE=$(date +%Y-%m-%d_%H-%M-%S)
BACKUP_DIR="/backup/postgresql"
LOG="/var/log/backup.log"

mkdir -p $BACKUP_DIR

# Sauvegarde PostgreSQL
pg_dump -U postgres production > $BACKUP_DIR/db_$DATE.sql

# Compression
gzip $BACKUP_DIR/db_$DATE.sql

# Rotation : garder 7 jours
find $BACKUP_DIR -name "db_*.sql.gz" -mtime +7 -delete

echo "[$DATE] Sauvegarde terminée." >> $LOG
```

### 3. Scripts PowerShell (Windows)

**Script 1 : Création des utilisateurs AD**
```powershell
# Create-Users.ps1
# Crée 100 utilisateurs dans Active Directory

Import-Module ActiveDirectory

$users = @(
    @{Name="Alice Martin"; Login="amartin"; Dept="IT"},
    @{Name="Bob Dupont"; Login="bdupont"; Dept="RH"},
    # ... 100 utilisateurs
)

foreach ($user in $users) {
    New-ADUser `
        -Name $user.Name `
        -SamAccountName $user.Login `
        -UserPrincipalName "$($user.Login)@entreprise.local" `
        -Department $user.Dept `
        -AccountPassword (ConvertTo-SecureString "P@ssw0rd2026!" -AsPlainText -Force) `
        -Enabled $true
}

Write-Host "100 utilisateurs créés avec succès."
```
