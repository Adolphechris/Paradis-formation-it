# Milestone J300a — Épreuve de Synthèse Bachelor BIT

> [!IMPORTANT]
> **MILESTONE J300 — DIPLÔME BACHELOR BIT**  
> Cette épreuve valide l'ensemble des compétences acquises durant les Semestres 1 à 4 (J01–J200).  
> **Condition de Réussite :** Vous devez obtenir un score minimum de **75% (38/50 bonnes réponses)** pour accéder à la composante suivante (J300b).

---

## 🎯 Objectifs de l'Épreuve

- 🧠 Valider la maîtrise des fondamentaux Linux/Windows, Bash, Python, SQL, Git.
- 🌐 Valider la maîtrise des réseaux TCP/IP, DNS, DHCP, routage, pare-feu.
- 🛡️ Valider la maîtrise des concepts de sécurité (CIA, permissions, chiffrement, firewall).
- ☁️ Valider la maîtrise du cloud computing, Docker, Terraform, CI/CD.
- 📊 Mesurer le niveau de préparation au Master Cybersecurity (S5–S12).

- ⏳ Durée : 2 heures.

## ❓ Banque de 50 Questions — Épreuve J300a

### Partie 1 : Linux & Bash (Q1–Q10)

**Q1 : Quelle commande affiche le chemin absolu du répertoire courant ?**
- A) `ls`
- B) `pwd`
- C) `cd`
- D) `mkdir`

*Réponse : B — `pwd` (Print Working Directory) affiche le chemin absolu depuis la racine `/`.*

**Q2 : Que fait la commande `chmod 750 script.sh` ?**
- A) Rend le script lisible par tous
- B) Donne tous les droits au propriétaire, lecture+exécution au groupe, rien aux autres
- C) Supprime le script
- D) Rend le script exécutable par tous

*Réponse : B — 7=rwx propriétaire, 5=rx groupe, 0=--- autres.*

**Q3 : Quelle est la différence entre `cp` et `mv` ?**
- A) `cp` copie, `mv` déplace/renomme
- B) `cp` supprime, `mv` copie
- C) Aucune différence
- D) `cp` est plus rapide que `mv`

*Réponse : A — `cp` duplique, `mv` déplace ou renomme.*

**Q4 : Comment lister tous les fichiers cachés d'un dossier ?**
- A) `ls`
- B) `ls -a`
- C) `ls -l`
- D) `ls -d`

*Réponse : B — `-a` affiche les fichiers commençant par un point `.`.*

**Q5 : Que fait `echo $?` après une commande ?**
- A) Affiche le code de retour de la dernière commande
- B) Affiche le contenu d'un fichier
- C) Supprime un fichier
- D) Crée un dossier

*Réponse : A — `$?` contient le code de retour de la dernière commande (0 = succès).*

**Q6 : Quelle commande permet de chercher une chaîne dans un fichier ?**
- A) `sort`
- B) `grep`
- C) `wc`
- D) `find`

*Réponse : B — `grep` recherche et affiche les lignes contenant la chaîne.*

**Q7 : Que fait `sudo systemctl start nginx` ?**
- A) Arrête Nginx
- B) Démarre le service Nginx avec les droits administrateur
- C) Installe Nginx
- D) Supprime Nginx

*Réponse : B — `systemctl start` démarre le service, `sudo` élève les privilèges.*

**Q8 : Quelle est la taille d'un inode ?**
- A) Variable selon le système de fichiers
- B) Toujours 1024 octets
- C) Toujours 4096 octets
- D) Dépend du fichier

*Réponse : A — La taille d'inode varie selon le système de fichiers (ext4, XFS, etc.).*

**Q9 : Que fait `|` (pipe) dans une commande ?**
- A) Redirige la sortie d'une commande vers l'entrée de la suivante
- B) Crée un nouveau fichier
- C) Supprime un dossier
- D) Affiche l'aide

*Réponse : A — Le pipe `|` chaîne les commandes : sortie de gauche → entrée de droite.*

**Q10 : Comment exécuter un script Bash ?**
- A) `sh script.sh` ou `bash script.sh` ou `chmod +x script.sh && ./script.sh`
- B) `open script.sh`
- C) `run script.sh`
- D) `execute script.sh`

*Réponse : A — Plusieurs méthodes : `bash script.sh`, `sh script.sh`, ou rendre exécutable + `./`.*

### Partie 2 : Windows & PowerShell (Q11–Q15)

**Q11 : Quelle est la différence principale entre Bash et PowerShell ?**
- A) Bash traite du texte, PowerShell traite des objets .NET
- B) PowerShell est plus vieux que Bash
- C) Bash est propriétaire, PowerShell est open-source
- D) Aucune différence

*Réponse : A — Bash manipule du texte brut, PowerShell manipule des objets structurés.*

**Q12 : Que fait `Get-Process | Where-Object {$_.CPU -gt 10}` ?**
- A) Liste les processus avec CPU > 10
- B) Tue tous les processus
- C) Installe un nouveau programme
- D) Formate le disque

*Réponse : A — Filtre les processus dont la propriété CPU est supérieure à 10.*

**Q13 : Quelle cmdlet PowerShell liste les services ?**
- A) `Get-Service`
- B) `Show-Service`
- C) `List-Service`
- D) `Find-Service`

*Réponse : A — `Get-Service` affiche tous les services Windows.*

**Q14 : Où sont stockées les configurations Windows ?**
- A) Dans des fichiers texte uniquement
- B) Dans la Base de Registre (Registry)
- C) Dans le BIOS seulement
- D) Dans le cloud seulement

*Réponse : B — Windows stocke la majeure partie des configurations dans la Base de Registre.*

**Q15 : Qu'est-ce qu'une GPO ?**
- A) Une stratégie de groupe pour configurer les postes Windows en entreprise
- B) Un fichier texte
- C) Un programme antivirus
- D) Un type de disque dur

*Réponse : A — GPO (Group Policy Object) applique des configurations centralisées.*

### Partie 3 : Réseaux (Q16–Q25)

**Q16 : Quelle couche du modèle OSI correspond au protocole TCP ?**
- A) Couche 1 (Physique)
- B) Couche 3 (Réseau)
- C) Couche 4 (Transport)
- D) Couche 7 (Application)

*Réponse : C — TCP est un protocole de la couche Transport (couche 4).*

**Q17 : Quelle est la différence entre TCP et UDP ?**
- A) TCP est orienté connexion avec accusé de réception, UDP est sans connexion
- B) UDP est plus fiable que TCP
- C) TCP ne fonctionne pas sur Internet
- D) Aucune différence

*Réponse : A — TCP garantit la livraison (3-way handshake), UDP est "fire and forget".*

**Q18 : Que fait un routeur ?**
- A) Relie des réseaux différents et achemine les paquets
- B) Stocke des fichiers
- C) Affiche des pages web
- D) Imprime des documents

*Réponse : A — Le routeur achemine les paquets entre réseaux distincts.*

**Q19 : Quel port utilise HTTP ?**
- A) 21
- B) 22
- C) 80
- D) 443

*Réponse : C — HTTP utilise le port 80 par défaut.*

**Q20 : Quel port utilise HTTPS ?**
- A) 21
- B) 22
- C) 80
- D) 443

*Réponse : D — HTTPS utilise le port 443 par défaut.*

**Q21 : Qu'est-ce qu'une adresse IP ?**
- A) L'identifiant logique d'un équipement sur un réseau
- B) L'adresse MAC gravée sur la carte réseau
- C) Un nom de domaine
- D) Un mot de passe

*Réponse : A — L'IP est l'adresse logique attribuée dynamiquement ou statiquement.*

**Q22 : Que fait DNS ?**
- A) Traduit un nom de domaine (ex: google.com) en adresse IP
- B) Attribue des adresses IP automatiquement
- C) Sécurise les connexions
- D) Transfère des fichiers

*Réponse : A — DNS fait la correspondance nom de domaine ↔ adresse IP.*

**Q23 : Qu'est-ce qu'un VLAN ?**
- A) Un réseau local virtuel pour segmenter un réseau physique
- B) Un type de câble réseau
- C) Un protocole de chiffrement
- D) Un système d'exploitation

*Réponse : A — Un VLAN isole logiquement des stations sur un même switch physique.*

**Q24 : Que fait NAT ?**
- A) Traduit des adresses IP privées en adresse IP publique
- B) Attribue des noms de domaine
- C) Crypte les données
- D) Mesure la bande passante

*Réponse : A — NAT (Network Address Translation) permet à plusieurs machines privées d'accéder à Internet avec une seule IP publique.*

**Q25 : Quelle commande Linux affiche la table de routage ?**
- A) `ip route`
- B) `route show`
- C) `netstat -r`
- D) A et C

*Réponse : D — `ip route` (moderne) et `netstat -r` (ancien) affichent la table de routage.*

### Partie 4 : Sécurité (Q26–Q35)

**Q26 : Que signifie la trinité CIA en cybersécurité ?**
- A) Confidentialité, Intégrité, Disponibilité
- B) Central Intelligence Agency
- C) Command Line Interface
- D) Computer Incident Action

*Réponse : A — CIA = Confidentialité, Intégrité, Disponibilité.*

**Q27 : Qu'est-ce qu'un firewall ?**
- A) Un dispositif qui filtre le trafic réseau selon des règles
- B) Un antivirus
- C) Un type de virus
- D) Un câble réseau

*Réponse : A — Le firewall (pare-feu) applique des règles de filtrage.*

**Q28 : Que fait `ufw allow 22/tcp` ?**
- A) Autorise le trafic TCP sur le port 22 (SSH)
- B) Bloque le port 22
- C) Installe SSH
- D) Supprime le firewall

*Réponse : A — UFW autorise le trafic TCP entrant sur le port 22.*

**Q29 : Qu'est-ce que le chiffrement symétrique ?**
- A) Même clé pour chiffrer et déchiffrer
- B) Deux clés différentes (publique/privée)
- C) Pas de clé
- D) Chiffrement impossible à casser

*Réponse : A — Chiffrement symétrique = même clé pour chiffrer et déchiffrer (ex: AES).*

**Q30 : Qu'est-ce que le chiffrement asymétrique ?**
- A) Deux clés (publique pour chiffrer, privée pour déchiffrer)
- B) Une seule clé
- C) Pas de clé
- D) Chiffrement seulement pour les mots de passe

*Réponse : A — Asymétrique = paire de clés (ex: RSA).*

**Q31 : Qu'est-ce qu'un VPN ?**
- A) Un tunnel chiffré entre deux réseaux sur Internet
- B) Un type de virus
- C) Un réseau sans fil gratuit
- D) Un protocole de messagerie

*Réponse : A — VPN (Virtual Private Network) crée un tunnel chiffré.*

**Q32 : Qu'est-ce que le MITM (Man-in-the-Middle) ?**
- A) Une attaque où l'attaquant intercepte la communication entre deux parties
- B) Un protocole sécurisé
- C) Un type de firewall
- D) Un système de détection d'intrusion

*Réponse : A — MITM = l'attaquant se place entre l'émetteur et le récepteur.*

**Q33 : Que fait un IDS/IPS ?**
- A) Détecte (IDS) / Bloque (IPS) les attaques connues
- B) Attribue des adresses IP
- C) Crypte les données
- D) Gère les utilisateurs

*Réponse : A — IDS = détection, IPS = détection + blocage actif.*

**Q34 : Qu'est-ce que le principe du moindre privilège ?**
- A) Un utilisateur n'a que les droits strictement nécessaires
- B) Tous les utilisateurs sont administrateur
- C) Les droits sont attribués aléatoirement
- D) Il n'y a pas de gestion des droits

*Réponse : A — Moindre privilège = droits minimums pour accomplir la tâche.*

**Q35 : Que fait `sudo` ?**
- A) Exécute une commande avec les droits administrateur (root)
- B) Supprime un fichier
- C) Éteint l'ordinateur
- D) Installe un antivirus

*Réponse : A — `sudo` (Super User DO) élève temporairement les privilèges.*

### Partie 5 : Cloud, Conteneurs & IaC (Q36–Q50)

**Q36 : Qu'est-ce qu'une VM (Virtual Machine) ?**
- A) Un ordinateur virtuel exécuté sur un hyperviseur
- B) Un fichier texte
- C) Un type de disque dur
- D) Un virus

*Réponse : A — Une VM est une instance de système d'exploitation virtualisée.*

**Q37 : Quelle est la différence principale entre une VM et un conteneur ?**
- A) La VM inclut un OS complet, le conteneur partage le noyau de l'hôte
- B) Le conteneur est plus lent que la VM
- C) La VM ne peut pas exécuter Linux
- D) Aucune différence

*Réponse : A — VM = OS complet virtualisé, conteneur = processus isolé partageant le noyau.*

**Q38 : Qu'est-ce que Docker ?**
- A) Une plateforme de conteneurisation
- B) Un système d'exploitation
- C) Un langage de programmation
- D) Un type de base de données

*Réponse : A — Docker est la plateforme standard pour créer et exécuter des conteneurs.*

**Q39 : Qu'est-ce qu'un Dockerfile ?**
- A) Un fichier texte qui décrit comment construire une image Docker
- B) Un fichier binaire
- C) Un type de conteneur
- D) Un protocole réseau

*Réponse : A — Le Dockerfile contient les instructions de build de l'image.*

**Q40 : Qu'est-ce que Terraform ?**
- A) Un outil d'Infrastructure as Code (IaC)
- B) Un antivirus
- C) Un langage de programmation
- D) Un système d'exploitation

*Réponse : A — Terraform permet de définir et déployer de l'infrastructure en code.*

**Q41 : Qu'est-ce qu'un provider Terraform ?**
- A) Le cloud provider cible (AWS, Azure, GCP, etc.)
- B) Un type de base de données
- C) Un langage de script
- D) Un protocole réseau

*Réponse : A — Le provider connecte Terraform à un cloud provider (AWS, Azure...).*

**Q42 : Qu'est-ce que le state Terraform (`terraform.tfstate`) ?**
- A) Le fichier qui mappe le code Terraform vers les ressources réelles déployées
- B) Un fichier de logs
- C) Un fichier de configuration
- D) Un fichier de sauvegarde

*Réponse : A — Le state est la source de vérité entre Terraform et le cloud.*

**Q43 : Que fait `terraform plan` ?**
- A) Affiche les modifications qui seront appliquées sans les exécuter
- B) Applique les modifications directement
- C) Supprime l'infrastructure
- D) Crée un nouveau projet

*Réponse : A — `plan` montre un aperçu des changements avant application.*

**Q44 : Qu'est-ce que CI/CD ?**
- A) Intégration Continue / Déploiement Continu — automatisation du build, test et déploiement
- B) Un protocole réseau
- C) Un type de base de données
- D) Un langage de programmation

*Réponse : A — CI/CD automatise le cycle de vie du logiciel (build → test → deploy).*

**Q45 : Qu'est-ce qu'un pipeline CI/CD ?**
- A) Une série d'étapes automatisées (build, test, scan, deploy)
- B) Un tuyau physique
- C) Un type de conteneur
- D) Un protocole réseau

*Réponse : A — Le pipeline est la chaîne d'étapes automatisées.*

**Q46 : Qu'est-ce que GitHub Actions ?**
- A) Une plateforme de CI/CD intégrée à GitHub
- B) Un type de conteneur
- C) Un système d'exploitation
- D) Un langage de programmation

*Réponse : A — GitHub Actions exécute des workflows automatisés déclenchés par des événements Git.*

**Q47 : Qu'est-ce qu'un runner GitHub Actions ?**
- A) La machine virtuelle qui exécute les étapes du workflow
- B) Un type de fichier
- C) Un protocole réseau
- D) Un langage de script

*Réponse : A — Le runner est l'environnement d'exécution (VM Ubuntu, Windows, macOS).*

**Q48 : Que fait `aws ec2 run-instances` ?**
- A) Lance une instance EC2 (serveur virtuel AWS)
- B) Supprime une instance
- C) Liste les instances
- D) Modifie le security group

*Réponse : A — `run-instances` crée et lance une VM dans le cloud AWS.*

**Q49 : Qu'est-ce qu'un Security Group dans AWS ?**
- A) Un firewall virtuel qui contrôle le trafic entrant/sortant d'une instance
- B) Un groupe d'utilisateurs
- C) Un type de disque
- D) Un protocole de chiffrement

*Réponse : A — Le Security Group est un firewall virtuel stateful.*

**Q50 : Qu'est-ce que l'Infrastructure as Code (IaC) ?**
- A) Gérer et provisionner de l'infrastructure via du code versionné
- B) Écrire du code dans des fichiers infrastructure
- C) Un langage de programmation
- D) Un type de serveur

*Réponse : A — L'IaC rend l'infrastructure reproductible, versionnée et auditable.*
