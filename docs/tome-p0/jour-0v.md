## ❓ Banque des 40 Questions de l'Examen de Transition

### Format S1 (J0p)

**Q1 : Combien de sections principales compose une journée S1 ?**
- A) 1 section (théorie uniquement)
- B) 3 sections (théorie, TP, QCM)
- C) 4 sections (Narration, Anatomie Technique, Atelier Pratique, Diagnostic & Réflexes Terrain)
- D) 5 sections

*Réponse : C — Une journée S1 comporte 4 sections principales.*

**Q2 : Quelle section S1 vous apprend à dépanner des erreurs ?**
- A) Narration & Intuition
- B) Anatomie Technique
- C) Atelier Pratique Hands-on
- D) Diagnostic & Réflexes Terrain

*Réponse : D — Diagnostic & Réflexes Terrain est dédiée au dépannage.*

**Q3 : Quel est le seuil de réussite pour un QCM quotidien S1 ?**
- A) 50%
- B) 75% (4/5 bonnes réponses)
- C) 100%
- D) Pas de seuil

*Réponse : B — Le seuil est de 75%.*

**Q4 : Qu'est-ce qu'un livrable portfolio ?**
- A) Un fichier vide
- B) Un script, une capture ou un rapport prouvant une compétence
- C) Un examen blanc
- D) Un mot de passe

*Réponse : B — Un livrable portfolio est une preuve concrète de compétence.*

**Q5 : Pourquoi le format S1 est-il plus exigeant que le format S0 ?**
- A) Pour embêter les apprenants
- B) Parce qu'il prépare au métier d'administrateur système en production
- C) Parce que S0 est déjà parfait
- D) Il n'y a pas de différence

*Réponse : B — Le format S1 simule la réalité professionnelle.*

### Codes Compétences (J0q)

**Q6 : Que signifie le code compétence `BIT-02` ?**

- B) Administration Linux & Shell
- C) Réseaux sans fil
- D) Intelligence artificielle

*Réponse : B — BIT-02 correspond à Administration Linux & Shell.*

**Q7 : Que signifie le code compétence `SEC-01` ?**
- A) Gestion des identités et accès
- B) Développement web
- C) Cloud computing
- D) Architecture matérielle

*Réponse : A — SEC-01 couvre la gestion des identités et accès.*

**Q8 : Que signifie le niveau cible "A" pour une compétence ?**
- A) Awareness — connaissance théorique
- B) Basic — application guidée
- C) Confirmed — autonome
- D) Expert — peut former

*Réponse : A — Niveau A = Awareness, connaissance théorique.*

**Q9 : À quoi servent les codes compétences ?**
- A) À décorer les fichiers
- B) À tracer les compétences, préparer les certifications et valoriser l'employabilité
- C) À rendre les fichiers plus longs
- D) À confondre les apprenants

*Réponse : B — Les codes compétences servent à la traçabilité, aux certifications et à l'employabilité.*

**Q10 : Dans quel famille de codes trouve-t-on les compétences en réseaux ?**
- A) BIT
- B) SEC
- C) NET
- D) DEV

*Réponse : C — La famille NET couvre les compétences réseaux.*

### Diagnostic & Réflexes Terrain (J0r)

**Q11 : Quelle est la première règle d'or du débogueur ?**
- A) Éteindre l'ordinateur
- B) Ne jamais paniquer — un message d'erreur est un diagnostic précieux
- C) Réinstaller le système
- D) Formater le disque

*Réponse : B — Un message d'erreur contient l'explication du problème.*

**Q12 : Que signifie le code de retour `$? = 0` ?**
- A) Erreur critique
- B) Succès de la dernière commande
- C) Le disque est plein
- D) Le réseau est coupé

*Réponse : B — Un code de retour 0 signifie succès.*

**Q13 : Quelle commande affiche le manuel officiel d'une commande Linux ?**
- A) `readme`
- B) `man`
- C) `help`
- D) `doc`

*Réponse : B — `man` ouvre les pages de documentation officielles.*

**Q14 : Face à "Permission denied", quel est le premier réflexe ?**
- A) Supprimer le fichier
- B) Vérifier les permissions et utiliser sudo si nécessaire
- C) Redémarrer l'ordinateur
- D) Ignorer l'erreur

*Réponse : B — Vérifier les permissions et utiliser sudo si vous avez les droits.*

**Q15 : Quelle commande affiche l'espace disque disponible ?**
- A) `free -h`
- B) `df -h`
- C) `ls -la`
- D) `ps aux`

*Réponse : B — `df -h` affiche l'espace disque disponible.*

### Portfolio (J0s)

**Q16 : Qu'est-ce qu'un livrable portfolio ?**
- A) Un fichier Word vierge
- B) Un script, une capture ou un rapport produit pendant la journée
- C) Un examen blanc
- D) Une vidéo YouTube

*Réponse : B — Un livrable portfolio est une preuve concrète de compétence.*

**Q17 : Pourquoi le portfolio est-il essentiel sur le marché nord-américain ?**
- A) Les recruteurs cherchent des preuves de compétence, pas juste des certificats
- B) C'est obligatoire par la loi
- C) Ça sert à décorer le bureau
- D) Ça n'a aucune utilité

*Réponse : A — Les recruteurs valident votre capacité par des projets concrets.*

**Q18 : Quels sont les 5 critères de qualité d'un livrable ?**
- A) Fonctionnel, documenté, reproductible, professionnel, prenable en main
- B) Court, rapide, gratuit, simple, rapide
- C) Long, complexe, cher, difficile, long
- D) Coloré, animé, drôle, musical, rapide

*Réponse : A — Les 5 critères de qualité.*

**Q19 : Comment rendre un script Bash exécutable ?**
- A) `rm script.sh`
- B) `chmod +x script.sh`
- C) `cp script.sh /tmp`
- D) `cat script.sh`

*Réponse : B — `chmod +x` ajoute le droit d'exécution.*

**Q20 : Où doit-on stocker son portfolio ?**
- A) N'importe où
- B) Dans une structure organisée par semestre et par jour
- C) Sur un disque externe seulement
- D) Dans la corbeille

*Réponse : B — Structure organisée par semestre et par jour.*

### Git & GitHub (J0u)

**Q26 : Que fait la commande `git init` ?**
- A) Initialise un nouveau dépôt Git dans le dossier courant
- B) Supprime tous les fichiers
- C) Installe un nouveau programme
- D) Formate le disque

*Réponse : A — `git init` crée un nouveau dépôt Git.*

**Q27 : Que fait la commande `git add` ?**
- A) Supprime un fichier
- B) Ajoute des fichiers à la zone de staging
- C) Envoie vers GitHub
- D) Crée une branche

*Réponse : B — `git add` prépare les fichiers pour le commit.*

**Q28 : Que fait la commande `git commit -m "message"` ?**
- A) Envoie vers GitHub
- B) Sauvegarde les fichiers avec un message descriptif
- C) Supprime le dépôt
- D) Crée un nouveau dossier

*Réponse : B — `git commit` sauvegarde avec un message.*

**Q29 : Quelle commande envoie vos commits vers GitHub ?**
- A) `git pull`
- B) `git push`
- C) `git delete`
- D) `git format`

*Réponse : B — `git push` envoie vers le serveur distant.*

**Q30 : Pourquoi commit souvent ?**
- A) Pour occuper de l'espace disque
- B) Pour pouvoir revenir en arrière facilement et tracer son évolution
- C) Pour ralentir l'ordinateur
- D) Ça n'a aucun intérêt

*Réponse : B — Committer souvent permet de revenir en arrière et de tracer son évolution.*

### Application pratique

**Q36 : Vous tapez `nginx` et obtenez `command not found`. Quel est votre premier réflexe ?**
- A) Réinstaller le système
- B) Vérifier si nginx est installé avec `which nginx`
- C) Ignorer l'erreur
- D) Éteindre l'ordinateur

*Réponse : B — Vérifier si la commande est installée.*

**Q37 : Vous voulez modifier `/etc/hosts` mais obtenez `Permission denied`. Que faites-vous ?**
- A) Supprimer le fichier
- B) Utiliser `sudo nano /etc/hosts`
- C) Formater le disque
- D) Rien

*Réponse : B — Utiliser sudo pour obtenir les droits administrateur.*

**Q38 : Vous avez créé un script `backup.sh`. Comment le rendre exécutable ?**
- A) `rm backup.sh`
- B) `chmod +x backup.sh`
- C) `cp backup.sh /tmp`
- D) `cat backup.sh`

*Réponse : B — `chmod +x` ajoute le droit d'exécution.*

**Q39 : Vous voulez sauvegarder votre travail avec Git. Quelle séquence ?**
- A) `git add .` → `git commit -m "message"` → `git push`
- B) `git delete` → `git format`
- C) `git install` → `git run`
- D) `git stop` → `git quit`

*Réponse : A — add, commit, push est la séquence standard.*
