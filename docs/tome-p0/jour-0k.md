## 📖 1. La Naissance de Linux & du Logiciel Libre

### 1.1 Richard Stallman et le Projet GNU (1983)
Dans les années 1980, le chercheur Richard Stallman crée le projet **GNU** et la FSF (*Free Software Foundation*). Son objectif : créer un système d'exploitation entièrement libre où chacun a le droit de lire, modifier, partager et améliorer le code source.

### 1.2 Linus Torvalds et le Noyau Linux (1991)
En 1991, un jeune étudiant finlandais de 21 ans nommé **Linus Torvalds** crée le cœur manquant du projet : le **Noyau Linux**. En combinant le Noyau de Linus avec les outils du projet GNU, le système d'exploitation universel **GNU/Linux** est né.

## 📖 2. Les 3 Grandes Familles de Distributions Linux

Une **distribution Linux** est un système prêt à l'emploi qui assemble le noyau Linux, des logiciels utilitaires, un gestionnaire de paquets et une interface utilisateur :

1. **Famille Debian / Ubuntu** :
   - Très populaire, réputée pour sa stabilité et sa communauté immense.
   - Gestionnaire de paquets : `apt` (fichiers `.deb`).
2. **Famille RedHat / Enterprise Linux (RHEL, Fedora, Rocky Linux)** :
   - Le standard absolu dans les banques, institutions et grands comptes d'entreprise.
   - Gestionnaire de paquets : `dnf` / `rpm` (fichiers `.rpm`).
3. **Famille Arch Linux / Alpine Linux** :
   - Ultra-légère, idéale pour les experts ou les conteneurs Docker (Alpine Linux).

## ❓ Banque de QCM & Test du Jour (5 Questions)

**Q1 : Qui est le créateur initial du Noyau Linux en 1991 ?**
- A) Steve Jobs
- B) Linus Torvalds
- C) Bill Gates
- D) Mark Zuckerberg

*Réponse : B — Linus Torvalds a créé le noyau Linux en 1991 alors qu'il était étudiant en Finlande.*

**Q2 : Que garantit la licence Open Source / GNU GPL pour un utilisateur ?**
- A) L'interdiction d'utiliser l'ordinateur la nuit
- B) La liberté de lire, modifier, étudier, améliorer et redistribuer le code source
- C) L'obligation de payer un abonnement mensuel
- D) L'interdiction de travailler en entreprise

*Réponse : B — L'Open Source garantit la transparence et les libertés fondamentales d'utilisation et de modification du code.*

**Q3 : Qu'est-ce qu'une "Distribution Linux" ?**
- A) Une publicité télévisée
- B) Un assemblage complet d'un noyau Linux, d'outils utilitaires, d'un gestionnaire de paquets et d'une interface
- C) Un câble réseau de couleur rouge
- D) Une marque de processeur

*Réponse : B — Une distribution est un système d'exploitation clé en main basé sur le noyau Linux.*

**Q4 : Quel gestionnaire de paquets est utilisé par les distributions de la famille Debian et Ubuntu ?**
- A) `apt`
- B) `dnf`
- C) `pacman`
- D) `exe`

*Réponse : A — `apt` (Advanced Package Tool) est le gestionnaire de paquets standard des systèmes Debian/Ubuntu.*

**Q5 : Pourquoi Linux est-il le système privilégié dans les serveurs du Cloud mondial et de la Cybersécurité ?**
- A) Parce qu'il est impossible d'y installer des jeux
- B) Pour sa stabilité légendaire, sa sécurité robuste, son caractère gratuit/open source et sa légèreté
- C) Parce qu'il est fabriqué par une seule entreprise
- D) Parce qu'il nécessite un écran tactile

*Réponse : B — La robustesse, la sécurité et la gratuité de Linux en font le roi incontesté des infrastructures Cloud.*
