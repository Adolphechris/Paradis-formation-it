## 📖 1. Les 4 Outils Indispensables de l’Ingénieur IT

### 1.1 L'Éditeur de Code (Visual Studio Code & Vim)
- **VS Code** : L'éditeur graphique le plus populaire au monde, doté d'extensions puissantes pour la coloration syntaxique, Git et l'IA.
- **Vim / Neovim** : L'éditeur textuel ultraléger intégré dans tous les serveurs Linux. Indispensable pour éditer des fichiers directement en ligne de commande.

### 1.2 La Virtualisation Locale (VirtualBox / Proxmox / KVM)
Un logiciel de virtualisation permet de créer des **Machines Virtuelles (VM)** — des ordinateurs virtuels s'exécutant dans une fenêtre de votre PC hôte. Idéal pour tester Linux ou faire des labs de sécurité sans risquer d'endommager votre propre ordinateur !

### 1.3 Le Contrôle de Version (Git & GitHub)
**Git** est l'outil indispensable qui enregistre l'historique complet des modifications de votre code. **GitHub** est la plateforme cloud mondiale où les développeurs partagent et collaborent sur leurs projets.

### 1.4 L'Analyseur de Paquets Réseau (Wireshark)
**Wireshark** est le "scanner à rayons X" des réseaux. Il permet de capturer et d'inspecter chaque paquet de données qui transite sur votre carte réseau.

## ❓ Banque de QCM & Test du Jour (5 Questions)

**Q1 : À quoi sert l'éditeur textuel Vim sous Linux ?**
- A) À lire des vidéos HD
- B) À éditer des fichiers de code et de configuration directement dans le terminal
- C) À remplacer la carte mémoire RAM
- D) À nettoyer le ventilateur

*Réponse : B — Vim est l'éditeur textuel terminal universel présent sur quasiment tous les serveurs Linux.*

**Q2 : Que permet un logiciel de virtualisation comme VirtualBox ?**
- A) De nettoyer le disque dur
- B) D'exécuter un ou plusieurs systèmes d'exploitation complets (VMs) dans des fenêtres isolées sur son PC
- C) D'augmenter la vitesse d'Internet
- D) De fabriquer des câbles Ethernet

*Réponse : B — La virtualisation crée des environnements totalement isolés pour tester et faire des labs en sécurité.*

**Q3 : Quel outil est surnommé le "scanner à rayons X" du réseau en raison de sa capacité à analyser chaque paquet de données ?**
- A) VS Code
- B) Wireshark
- C) VirtualBox
- D) Git

*Réponse : B — Wireshark est l'analyseur de paquets de référence pour le réseau et la cybersécurité.*

**Q4 : À quoi sert l'outil Git pour un développeur ou administrateur système ?**
- A) À dessiner des schémas
- B) À sauvegarder et suivre l'historique précis de toutes les modifications apportées au code source
- C) À calculer la température du processeur
- D) À installer des polices d'écriture

*Réponse : B — Git est le gestionnaire de version décentralisé standard de toute l'industrie du logiciel.*

**Q5 : Quel est l'éditeur de code graphique le plus utilisé aujourd'hui pour programmer en Python, Bash ou Web ?**
- A) Bloc-Notes Windows
- B) Visual Studio Code (VS Code)
- C) Paint
- D) MS Word

*Réponse : B — VS Code est l'environnement de développement gratuit le plus populaire et étensible de l'industrie.*
