## 📖 1. Pourquoi deux shells ?

| Bash | PowerShell |
|---|---|
| Traite du **texte brut** | Traite des **objets .NET structurés** |
| Standard sur Linux/macOS | Standard sur Windows moderne |
| `ls`, `grep`, `awk`, `sed` | `Get-ChildItem`, `Where-Object`, `Select-Object` |
| Philosophie : "chaque outil fait une chose" | Philosophie : "tout est objet, tout est pipeline" |

**Analogies métier** :
- Bash = Excel (données en colonnes, texte brut).
- PowerShell = SAP (objets structurés avec propriétés : Nom, Prénom, Département).

---

## 📖 2. Correspondances essentielles

| Action | Bash | PowerShell |
|---|---|---|
| Lister un dossier | `ls -la` | `Get-ChildItem` ou `ls` |
| Compter les lignes | `wc -l` | `(Get-Content fichier.txt).Count` |
| Chercher une chaîne | `grep "erreur" fichier` | `Select-String "erreur" fichier` |
| Trier | `sort fichier.txt` | `Sort-Object` |
| Supprimer doublons | `sort \| uniq` | `Sort-Object -Unique` |
| Compter processus | `ps aux` | `Get-Process` |
| Tuer un processus | `kill 1234` | `Stop-Process -Id 1234` |
| Lire un fichier | `cat fichier.txt` | `Get-Content fichier.txt` |
| Écrire dans un fichier | `echo "texte" > fichier` | `Set-Content -Path fichier -Value "texte"` |

---

## 📖 3. Le pipeline PowerShell

### Concept clé
Dans Bash, le pipeline passe du **texte**. Dans PowerShell, le pipeline passe des **objets** avec des propriétés.

**Exemple Bash** :
```bash
ps aux | grep nginx | awk '{print $2}'
```
→ On parse du texte pour extraire le PID (colonne 2).

**Exemple PowerShell** :
```powershell
Get-Process nginx | Select-Object -ExpandProperty Id
```
→ On manipule l'objet `Process` et on extrait la propriété `Id`. Pas de parsing de texte.

## 🧪 Atelier Pratique : 5 conversions Bash → PowerShell

### Exercice 1 : Lister les fichiers .log
**Bash** : `ls -la *.log`
**PowerShell** : `Get-ChildItem -Filter *.log`

### Exercice 2 : Compter les processus
**Bash** : `ps aux | wc -l`
**PowerShell** : `(Get-Process).Count`

### Exercice 3 : Chercher "error" dans un fichier
**Bash** : `grep "error" /var/log/syslog`
**PowerShell** : `Select-String "error" /var/log/syslog`

### Exercice 4 : Trier et supprimer les doublons
**Bash** : `sort fichier.txt | uniq`
**PowerShell** : `Get-Content fichier.txt | Sort-Object -Unique`

### Exercice 5 : Tuer un processus par nom
**Bash** : `pkill nginx`
**PowerShell** : `Stop-Process -Name nginx -Force`

## ❓ Banque de QCM & Test du Jour (5 Questions)

**Q1 : Quelle est la différence fondamentale entre Bash et PowerShell ?**
- A) Bash traite du texte, PowerShell traite des objets
- B) PowerShell est plus vieux que Bash
- C) Bash est propriétaire
- D) Aucune différence

*Réponse : A — Bash = texte brut, PowerShell = objets .NET structurés.*

**Q2 : Que fait `Select-Object -ExpandProperty Id` ?**
- A) Extrait la propriété Id d'un objet
- B) Supprime un fichier
- C) Crée un dossier
- D) Formate le disque

*Réponse : A — `Select-Object` extrait une propriété spécifique de l'objet.*

**Q3 : Quelle commande PowerShell liste les processus ?**
- A) `Get-Process`
- B) `Show-Process`
- C) `List-Process`
- D) `Find-Process`

*Réponse : A — `Get-Process` affiche tous les processus en cours.*

**Q4 : Comment tuer un processus PowerShell par nom ?**
- A) `Stop-Process -Name nginx -Force`
- B) `kill nginx`
- C) `rm nginx`
- D) `del nginx`

*Réponse : A — `Stop-Process` est la cmdlet PowerShell pour terminer un processus.*

**Q5 : Pourquoi PowerShell utilise-t-il des objets plutôt que du texte ?**
- A) Pour éviter le parsing de texte et avoir des données structurées
- B) Pour être plus lent
- C) Pour casser la compatibilité
- D) Aucune raison

*Réponse : A — Les objets structurés évitent le parsing fragile du texte.*
