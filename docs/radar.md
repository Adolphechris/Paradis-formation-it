# Radar de Compétences

## Vue d'ensemble

Le radar de compétences affiche votre progression en temps réel sur 6 axes sectoriels :

| Axe | Score | Tome(s) |
| :--- | :---: | :--- |
| Support & Bureautique | — | P0 |
| Systèmes & Réseaux | — | P2, P3A |
| Développement & Algorithmique | — | P2, P3C |
| Base de Données & Analytique | — | P2, P3B |
| Cloud & Cybersécurité | — | P4 |
| Conformité & Culture Bancaire BCC | — | BCC + P5 |

## Mise à jour

Le radar se met à jour automatiquement à chaque journée complétée avec un score QCM enregistré.

### Calcul des scores
- **40%** — % de jours complétés dans le périmètre de l'axe
- **60%** — Moyenne des notes QCM dans le périmètre

*Le diagramme radar utilise Chart.js pour le rendu visuel.*
