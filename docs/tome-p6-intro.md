# Semestre 6 — Cybersécurité Avancée Expert (J251-J300)

## Présentation du Semestre 6

Le **Semestre 6** du parcours Cybersécurité Avancée (PARADIS IT) consolide et élargit l'expertise acquise au Semestre 5 pour atteindre le niveau **Expert International**. Les compétences développées ciblent directement les rôles les plus recherchés sur le marché mondial de la cybersécurité :

- **Bug Bounty Hunter** (HackerOne / Bugcrowd)
- **Penetration Tester Senior** (OSCP+, CRTO, BSCP)
- **Red Team Operator** (CRTO, CRTE, CRTL)
- **Cloud Security Architect** (CCSP, AWS SA-Pro)
- **Threat Intelligence Analyst** (GCTI, CTIA)
- **Application Security Engineer** (CSSLP, GWEB)
