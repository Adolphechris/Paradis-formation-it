# Aperçu du Programme PARADIS IT

## Méthodologie

Le programme suit les standards de l'**enseignement ouvert et à distance (ODL)**, inspiré de l'**UNISA** (University of South Africa). Il est conçu pour une autoformation intensive de **45 jours**, à raison de **14 heures par jour**, pour un total de **630 heures**.

---

## Architecture Pédagogique

### Chaque journée comprend :

1. **Objectifs d'apprentissage** — Ce que vous maîtriserez à la fin de la journée
2. **Contenu théorique** — Explications structurées avec exemples
3. **Exemples pratiques** — Extraits de code commentés
4. **Exercices guidés** — Défis avec difficulté progressive
5. **Validation qualité /100** — Grille d'auto-évaluation
6. **Corrigés guidés mode tuteur** — Solutions détaillées avec explications pédagogiques

---

## Les 7 Tomes

### P0 — Socle Support (J1–J3)
Environnement de travail, bureautique, Web front-end, Git, Linux. Les bases indispensables pour tout professionnel IT.

### P2 — Fondations (J4–J11)
Python, structures de données, SQL, réseaux informatiques, Bash scripting. Le socle technique de tout développeur sysadmin.

### P3A — Administration Système (J12–J17)
Gestion des utilisateurs, permissions, cron, services systemd, scripts d'automatisation, monitoring.

### P3B — Base de Données & Analytique (J18–J22)
PostgreSQL, MySQL, modélisation relationnelle, requêtes complexes, analyse de données, indexation.

### P3C — Développement Web (J23–J28)
HTML/CSS/JavaScript, frameworks front-end, API REST, déploiement web, sécurité applicative.

### P4 — Cloud & Sécurité (J29–J35)
Cloud computing (AWS, GCP), cybersécurité, gouvernance IT (ITIL, ISO 27001), architecture réseau avancée.

### P5 — Préparation Tests (J36–J41)
Banques de QCM, simulations d'entretien techniques, examen blanc BCC (100 questions, chrono 2h).

### P6 — Portfolio & Soutenance (J42–J45)
Projets concrets, rapport d'employabilité, portfolio professionnel, simulation de soutenance orale.

---

## Module Spécial — Excellence BCC

En complément des tomes, un module dédié couvre :
- **Gouvernance IT** : ITIL v4, ISO 27001, PCA/PRA
- **Monétique** : SWIFT MT/MX (ISO 20022), RTGS, ACH, monnaie électronique
- **Culture institutionnelle** : fonctionnement de la Banque Centrale du Congo

---

## Prérequis

- Ordinateur fonctionnel (PC, Mac, tablette)
- Connexion internet (pour le premier accès et les mises à jour)
- Navigateur web moderne
- Aucun prérequis technique pour débuter P0
