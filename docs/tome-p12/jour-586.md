## Module 1 — GitHub Portfolio Architecture (2h)

### 📖 Pourquoi un Portfolio GitHub est votre meilleure CV

Pour un ingénieur IT senior, le code parle plus fort que les mots. Votre profil GitHub est examiné par les recruteurs techniques **avant même l'entretien téléphonique**. Un portfolio médiocre (dépôts vides, README absents, historique de commits en désordre) signale un manque de rigueur professionnelle.

```
ANATOMIE D'UN PROFIL GITHUB TECHNIQUE D'EXCELLENCE

  1. PROFIL README (github.com/username/username)
     ┌─────────────────────────────────────────────────────────────┐
     │  # 👋 Bonjour, je suis [Prénom] — Senior Platform Engineer │
     │                                                             │
     │  ## 🛠️ Stack Technique                                      │
     │  ![Python](badge) ![Kubernetes](badge) ![AWS](badge)       │
     │  ![Terraform](badge) ![Kafka](badge) ![Go](badge)          │
     │                                                             │
     │  ## 🏆 Certifications                                       │
     │  - AWS Solutions Architect Professional (SAP-C02)          │
     │  - Certified Kubernetes Security Specialist (CKS)          │
     │  - CISSP — Certified Information Systems Security Prof.    │
     │                                                             │
     │  ## 📊 GitHub Stats (badges dynamiques)                    │
     │  ![Stats](https://github-readme-stats.vercel.app/api?...)  │
     │                                                             │
     │  ## 🚀 Projets Phares                                       │
     │  - [PARADIS Platform](link) : Smart City IoT/AI Platform  │

  2. STRUCTURE D'UN DÉPÔT "PINNED" (Projet phare) :
     ┌─────────────────────────────────────────────────────────────┐
     │  README.md complet (Architecture, Installation, Démo GIF) │
     │  docs/ : Documentation technique (ADRs, OpenAPI)           │
     │  src/ : Code bien structuré, typé, testé (>80% coverage)  │
     │  tests/ : Unit + Integration + E2E tests                   │
     │  .github/workflows/ : CI/CD pipeline (badge statut)       │
     │  Dockerfile + docker-compose.yml                           │
```

## Module 2 — Blog Technique & Personal Branding (2h)

### 🔍 Anatomie d'un Article de Blog Technique qui Génère du Trafic

```
STRUCTURE D'UN ARTICLE TECHNIQUE VIRAL (>1000 vues)

  TITRE : Formule "Problème → Solution" ou "Nombre → Chose"
  Exemples :
  ✅ "How I Cut Our Kubernetes Costs by 60% Using KEDA and Spot Instances"
  ✅ "5 Security Mistakes Every Platform Engineer Makes (And How to Fix Them)"
  ✅ "Building a Production-Grade RAG Pipeline with LangChain and Qdrant"
  ❌ "Mon expérience avec Kubernetes" (trop vague)
  ❌ "Introduction à Docker" (déjà vu 10 000 fois)

  STRUCTURE NARRATIVE :
  1. HOOK (Accroche) — "Le lundi matin, notre k8s cluster consommait 40k€/mois..."
  2. PROBLÈME — Description technique précise avec métriques
  3. ANALYSE — Diagnostic, root cause, options évaluées
  4. SOLUTION — Code concret, architecture, diagrams
  5. RÉSULTATS — Métriques avant/après (chiffres réels)
  6. LESSONS LEARNED — Ce que vous auriez fait différemment
  7. CTA (Call to Action) — "Étoile le repo | Abonne-toi | Commente"

  PLATEFORMES & AUDIENCE :
  Dev.to     : Communauté développeurs (gratuit, bon SEO)
  Hashnode   : Auto-hébergé sur votre domaine (paradis.hashnode.dev)
  Medium     : Audience + large mais paywall
  Substack   : Newsletter technique (fidélisation)
  LinkedIn   : Articles B2B (visibilité recruteurs)
```

### 🔍 LinkedIn — Optimisation pour Senior Engineer

```
PROFIL LINKEDIN OPTIMISÉ POUR POSTE SENIOR

  TITRE (Headline) — 220 caractères — LE PLUS IMPORTANT :
  ❌ "Développeur chez Société X"  (banal, non-searchable)
  ✅ "Platform Engineer | AWS | Kubernetes | DevSecOps | PARADIS Masterclass"
  ✅ "Security Architect | CISSP | Zero-Trust | Cloud CISO-ready | ex-Google"

  RÉSUMÉ (About) — 2000 caractères max :
  - Paragraphe 1 : Votre identité professionnelle en 1–2 phrases percutantes

  - Paragraphe 3 : Ce que vous recherchez / ce que vous apportez
  - Footer : Certifications, Stack, Contact

  Format CAR (Challenge-Action-Result) pour chaque mission :
  "Réduire la dette de sécurité : Implémenté pipeline DevSecOps (SAST/SCA/SBOM)

  COMPÉTENCES (Skills) :
  Top 3 validées > 99 endorsements = crédibilité
  Ordre : Kubernetes, AWS, Python, Terraform, Security...

  RECOMMANDATIONS :
  Minimum 3 recommandations de managers/clients réels > Valeur immense
```

## Module 3 — Atelier Pratique : Portfolio README Generator (1h30)

### 🛠️ Script Python : GitHub Portfolio README Generator & Blog Post Template

```python
#!/usr/bin/env python3
"""
PARADIS — GitHub Portfolio README Generator & Blog Post Analyzer
Génère automatiquement un README professionnel GitHub et analyse
la qualité d'un titre d'article de blog technique.
"""
from dataclasses import dataclass, field
from typing import List, Dict, Optional
import re

@dataclass
class TechStack:
    category : str
    techs    : List[str]
    color    : str = "blue"

@dataclass
class Certification:
    name       : str
    badge_code : str   # Code court pour badge shields.io
    date       : str
    issuer     : str

@dataclass
class PinnedProject:
    name        : str
    description : str
    tech_stack  : List[str]
    github_url  : str
    demo_url    : Optional[str] = None
    stars       : int = 0

@dataclass
class EngineerProfile:
    name          : str
    title         : str
    tagline       : str
    location      : str
    stacks        : List[TechStack] = field(default_factory=list)
    certifications: List[Certification] = field(default_factory=list)
    projects      : List[PinnedProject] = field(default_factory=list)
    github_username: str = ""
    linkedin_url  : str = ""
    blog_url      : str = ""

class PortfolioReadmeGenerator:
    """Génère un README.md professionnel pour profil GitHub"""

    BADGE_COLORS = {
        "Python"    : "3776AB", "Kubernetes" : "326CE5",
        "AWS"       : "FF9900", "Terraform"  : "7B42BC",
        "Go"        : "00ADD8", "Rust"       : "000000",
        "Docker"    : "2496ED", "Linux"      : "FCC624",
    }

    def _make_badge(self, label: str, color: Optional[str] = None) -> str:
        safe_label = label.replace(" ", "_").replace("-", "--")
        col = color or self.BADGE_COLORS.get(label, "555555")
        return f"![{label}](https://img.shields.io/badge/{safe_label}-{col}?style=flat-square&logo={label.lower()}&logoColor=white)"

    def generate(self, profile: EngineerProfile) -> str:
        lines = []
        # Header
        lines.append(f"# 👋 Bonjour, je suis **{profile.name}**")
        lines.append(f"> *{profile.tagline}*\n")
        lines.append(f"📍 {profile.location}")
        if profile.linkedin_url:
            lines.append(f"[![LinkedIn](https://img.shields.io/badge/LinkedIn-Connect-0077B5?style=flat-square&logo=linkedin)](https://linkedin.com/in/{profile.linkedin_url})")
        if profile.blog_url:
            lines.append(f"[![Blog](https://img.shields.io/badge/Blog-Articles-FF5722?style=flat-square&logo=hashnode)](https://{profile.blog_url})")
        lines.append("")

        # Tech Stack
        lines.append("## 🛠️ Stack Technique\n")
        for stack in profile.stacks:
            badges = " ".join(self._make_badge(t) for t in stack.techs)
            lines.append(f"**{stack.category}** : {badges}\n")

        # Certifications
        if profile.certifications:
            lines.append("## 🏆 Certifications")
            for cert in profile.certifications:
                lines.append(f"- ✅ **{cert.name}** — {cert.issuer} ({cert.date})")
            lines.append("")

        # GitHub Stats
        if profile.github_username:
            lines.append("## 📊 GitHub Stats")
            lines.append(f"![Stats](https://github-readme-stats.vercel.app/api?username={profile.github_username}&show_icons=true&theme=dark&hide_border=true)\n")

        # Projets Phares
        if profile.projects:
            lines.append("## 🚀 Projets Phares\n")
            lines.append("| Projet | Description | Stack |")
            lines.append("|:---|:---|:---|")
            for p in profile.projects:
                stack_badges = ", ".join(f"`{t}`" for t in p.tech_stack[:3])
                link = f"[{p.name}]({p.github_url})"
                lines.append(f"| {link} | {p.description} | {stack_badges} |")
            lines.append("")

        lines.append("---")
        lines.append(f"*PARADIS IT Masterclass — 600 jours de formation intensive completés ✅*")
        return "\n".join(lines)

class BlogTitleAnalyzer:
    """Analyse la qualité d'un titre d'article de blog technique"""

    POWER_WORDS = ["how i", "why", "stop", "never", "always", "complete", "guide",
                   "mistakes", "secrets", "ultimate", "production", "real-world"]
    ENGAGEMENT_NUMBERS = re.compile(r'\b(\d+)\b')

    def analyze(self, title: str) -> dict:
        title_lower = title.lower()
        has_number  = bool(self.ENGAGEMENT_NUMBERS.search(title))
        has_power   = any(pw in title_lower for pw in self.POWER_WORDS)
        has_tech    = any(tech in title_lower for tech in ["kubernetes", "aws", "python", "ai", "docker", "k8s"])
        char_count  = len(title)

        score = 0
        feedback = []

        if has_number:
            score += 20; feedback.append("✅ Titre numéroté (ex: '5 façons...')")
        else:
            feedback.append("💡 Ajouter un nombre (ex: '3 erreurs à éviter')")

        if has_power:
            score += 25; feedback.append("✅ Mot de puissance détecté")
        else:
            feedback.append("💡 Ajouter un mot de puissance (How I, Why, Mistakes, Guide)")

        if has_tech:
            score += 20; feedback.append("✅ Technologie spécifique mentionnée")
        else:
            feedback.append("💡 Mentionner une technologie spécifique")

        if 40 <= char_count <= 70:
            score += 20; feedback.append("✅ Longueur optimale (40-70 car.)")
        elif char_count < 40:
            score += 5;  feedback.append(f"💡 Titre court ({char_count} car.) — développer")
        else:
            score += 10; feedback.append(f"💡 Titre long ({char_count} car.) — raccourcir")

        if "?" in title or ":" in title:
            score += 15; feedback.append("✅ Ponctuation engageante (? ou :)")

        label = "🌟 EXCELLENT" if score >= 80 else "✅ BON" if score >= 60 else "🟡 MOYEN" if score >= 40 else "❌ FAIBLE"
        return {"title": title, "score": score, "label": label, "feedback": feedback}


if __name__ == "__main__":
    # Profil de démonstration
    profile = EngineerProfile(
        name     = "Jean PARADIS",
        title    = "Senior Platform & Security Engineer",
        tagline  = "600 jours de Masterclass IT → Ingénieur Élite | PARADIS IT Graduate",
        location = "Paris, France 🇫🇷",
        github_username = "jean-paradis",
        linkedin_url    = "jean-paradis",
        blog_url        = "paradis.hashnode.dev",
        stacks = [
            TechStack("Cloud & DevOps",  ["AWS", "Kubernetes", "Terraform", "Docker"]),
            TechStack("Langages",        ["Python", "Go", "Bash"]),
            TechStack("Sécurité",        ["Linux"]),  # Représentation simplifiée
        ],
        certifications = [
            Certification("AWS SAP-C02", "aws", "2026-06", "Amazon Web Services"),
            Certification("CKS", "k8s", "2026-04", "CNCF"),
            Certification("CISSP", "isc2", "2026-08", "ISC²"),
        ],
        projects = [
            PinnedProject("paradis-platform", "Smart City Platform IoT+AI+5G+XR",
                          ["Python", "Kafka", "Kubernetes"], "https://github.com/jean-paradis/paradis-platform"),
            PinnedProject("k8s-security-toolkit", "CIS Benchmark K8s Auditor",
                          ["Python", "Kubernetes", "OPA"], "https://github.com/jean-paradis/k8s-security-toolkit"),
        ]
    )

    generator = PortfolioReadmeGenerator()
    readme    = generator.generate(profile)
    print("=== GITHUB PROFILE README GÉNÉRÉ ===\n")
    print(readme)

    # Analyse de titres
    print("\n=== ANALYSE DE TITRES D'ARTICLES TECHNIQUES ===")
    analyzer = BlogTitleAnalyzer()
    titles = [
        "How I Reduced Kubernetes Costs by 60% Using KEDA and Spot Instances",
        "Mon expérience avec Docker",
        "5 Security Mistakes Every Platform Engineer Makes in Production Kubernetes"
    ]
    for title in titles:
        result = analyzer.analyze(title)
        print(f"\n  Titre : {result['title'][:60]}")
        print(f"  Score : {result['score']}/100 — {result['label']}")
        for f in result["feedback"]:
            print(f"    {f}")
```

## Exercices Pratiques

### Exercice 1 — Optimisation de Titre LinkedIn

Transformez ce titre LinkedIn banal en un titre optimisé :

**Titre actuel :** *"Ingénieur DevOps chez Startup XYZ"*

**Éléments à intégrer :** AWS certified, spécialité Kubernetes, intérêt pour la sécurité, 5 ans d'expérience.

**Corrigé (exemples de titres optimisés) :**
- *"Platform Engineer | AWS SAP | Kubernetes Security (CKS) | DevSecOps | 5 ans d'expérience"*
- *"Senior DevOps → Platform Engineer | AWS Certified | K8s | Zero-Trust | Seeking Staff Eng roles"*
- *"Cloud Platform & Security Engineer | AWS | Kubernetes | Terraform | PARADIS IT Graduate"*

**Pourquoi ça fonctionne :** Mots-clés searchables (AWS, Kubernetes, DevSecOps), certifications visibles, niveau d'expérience, signal de positionnement (seeking).
