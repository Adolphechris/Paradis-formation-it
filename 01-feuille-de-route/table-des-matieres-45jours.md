**Note sur P1 (stratégie de recherche d'emploi) :** ce tome n'a pas de jours dédiés — il tourne en fil continu, environ 30-45 minutes prélevées chaque jour sur le temps déjà budgété.

**Rythme journalier type (14h) :**
- 2h : théorie/lecture ciblée
- 8h : pratique directe (exercices, projets, labs)
- 2h : révision et consolidation
- 1h30 : banque de questions (évaluation du jour)
- 30 min : suivi P1 (recherche d'emploi, CV, veille)

---

## TOME P0 — Socle professionnel immédiat (J1-J3, 42h)
**Jour 1 (14h)** : Windows professionnel, Excel avancé, Word/PowerPoint, Outlook, outils collaboratifs, banque de questions, suivi P1.  
**Jour 2 (14h)** : HTML, CSS, JavaScript (notions), Git/GitHub, banque de questions, suivi P1.  
**Jour 3 (14h)** : Linux CLI + usage avancé, auto-diagnostic, projet P0 (mini-site + dossier bureautique), banque de questions, suivi P1.

**Palier d'employabilité après J3 :** support technique / assistant informatique débutant.

---

## TOME P2 — Fondations techniques accélérées (J4-J11, 112h)
**Jour 4** : logique de programmation + Python bases + exercices + banque de questions.  
**Jour 5** : Python appliqué (fichiers, modules, POO, libs) + mini-projet.  
**Jour 6** : structures de données + complexité pratique + exercices Python.  
**Jour 7** : SQL bases + agrégation + exercices sur base réelle.  
**Jour 8** : SQL avancé + modélisation + transactions + projet base de données.  
**Jour 9** : réseaux TCP/IP + diagnostic pratique.  
**Jour 10** : Bash avancé + automatisation + Bash/SQL.  
**Jour 11** : projet de synthèse P2 (Bash + Python + SQL), révision, banque cumulative.

**Palier d'employabilité après J11 :** profil junior admin système / support avancé / data débutant.

---

## TOME P3-A — Administration systèmes et réseau (J12-J17, 84h)
**Jour 12** : Linux avancé (services, logs, permissions).  
**Jour 13** : Windows Server + notions Active Directory.  
**Jour 14** : virtualisation + Docker (bases et pratique).  
**Jour 15** : sécurité appliquée (durcissement, accès, incidents).  
**Jour 16** : supervision + résolution d'incidents + tickets/support.  
**Jour 17** : projet de synthèse axe A (infrastructure documentée sécurisée).

**Palier intermédiaire :** profil junior administration systèmes/réseau.

---

## TOME P3-B — Analyse de données (J18-J22, 70h)
**Jour 18** : statistiques appliquées + Excel/Python.  
**Jour 19** : SQL analytique avancé + modélisation + data cleaning.  
**Jour 20** : visualisation (Excel, Power BI ou équivalent, Python intro).  
**Jour 21** : concepts Big Data + pandas bases + transformation de données.  
**Jour 22** : cas business + projet de synthèse axe B (analyse complète).

**Palier intermédiaire :** profil data junior / missions analytiques en contexte professionnel.

---

## TOME P3-C — Développement web (J23-J28, 84h)
**Jour 23** : JavaScript approfondi + structuration frontend.  
**Jour 24** : framework moderne (React ou équivalent).  
**Jour 25** : backend + API REST + connexion base de données.  
**Jour 26** : ORM/requêtes + authentification + sécurité applicative.  
**Jour 27** : déploiement cloud + HTTPS + hébergement.  
**Jour 28** : architecture logicielle + projet de synthèse axe C (app complète déployée).

**Palier intermédiaire :** portfolio développeur web junior avec projet déployé.

---

## TOME P4 — Cloud, sécurité transversale et professionnalisation (J29-J35, 98h)
**Jour 29** : cloud fondamentaux + plateforme principale (AWS/Azure).  
**Jour 30** : réseau/sécurité cloud + bases de données managées + coûts.  
**Jour 31** : sécurité transversale (chiffrement, sauvegarde, accès).  
**Jour 32** : gouvernance IT + conformité + gestion de projet appliquée.  
**Jour 33** : anglais technique I (lecture, vocabulaire, rédaction).  
**Jour 34** : anglais technique II (entretien technique, simulation).  
**Jour 35** : projet de synthèse P4 (cas d'entreprise : cloud sécurisé documenté).

**Palier renforcé après J35 :** profil complet et crédible « Professionnel du numérique ».

---

## TOME P5 — Préparation intensive tests techniques et entretiens (J36-J41, 84h)
**Jour 36** : révision ciblée P0-P2 + banque massive chronométrée.  
**Jour 37** : révision ciblée P3-A/P3-B + banque massive chronométrée.  
**Jour 38** : révision ciblée P3-C/P4 + banque massive chronométrée.  
**Jour 39** : banque ciblée poste visé + simulation QCM et questions ouvertes.  
**Jour 40** : simulation test complet + simulation entretien technique oral.  
**Jour 41** : remédiation finale sur points faibles + mini-simulation de validation.

---

## TOME P6 — Portfolio final et consolidation (J42-J43, 28h)
**Jour 42** : sélection projets, rédaction technique, mise en forme portfolio.  
**Jour 43** : finalisation CV/profil en ligne, argumentaire de trajectoire d'accréditation et de collaboration UNISA, vérification du dossier candidature.

---

## J44-J45 — Révision générale et simulation finale (28h)
**Jour 44** : test technique complet en conditions réelles + remédiation finale.  
**Jour 45** : simulation d'entretien final + bilan global + validation finale portfolio.
