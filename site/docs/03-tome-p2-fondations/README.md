## 3) Synthèse des acquis techniques P2

### A. Programmation (J4-J6)
- Logique algorithmique (IPO, conditions, boucles, fonctions).
- Python bases et appliqué (fichiers, modules, POO, structures).
- Complexité pratique (Big-O, choix de structures selon cas).

### B. Données (J7-J8)
- SQL base (SELECT/WHERE/ORDER/LIMIT, DDL/DML/DQL).
- SQL avancé (jointures, CTE, vues, sous-requêtes, agrégations).
- Modélisation (ERD, 1NF/2NF/3NF) + transactions (ACID/TCL).

### C. Systèmes & exploitation (J9-J10)
- Réseaux TCP/IP et diagnostic (IP, DNS, DHCP, ICMP, RTT).
- Bash avancé et automatisation (pipes, redirections, scripts robustes, cron).
- Intégration Bash+SQL (exports contrôlés, logs, vérifications).

### D. Intégration finale (J11)
- Pipeline de synthèse Bash + SQL + Python.
- Logique de production orientée fiabilité, traçabilité et transmission (RCA/SOP).

## 5) Check-list de passage P3

### Prérequis techniques minimaux (à valider)
- [ ] Écrire et expliquer un script Python propre sur cas métier simple.
- [ ] Produire une requête SQL join + agrégation + justification du résultat.
- [ ] Exécuter un diagnostic réseau de bout en bout avec conclusion claire.
- [ ] Automatiser une tâche Bash avec logs et contrôle d'erreur.
- [ ] Présenter un mini-projet en 60-90 secondes (problème → solution → impact).

### Prérequis employabilité
- [ ] CV mis à jour avec preuves P2 concrètes.
- [ ] Portfolio enrichi d'au moins 2 preuves transversales (code + résultat + contexte).
- [ ] Pitch technique court prêt pour entretien.

### Décision de passage
- Si la majorité des cases est validée: **passage P3 recommandé**.
- Sinon: remédiation ciblée 24-48h avant démarrage P3-A.
